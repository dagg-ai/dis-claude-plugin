# dis status

Check project status including ingestion progress, connected integrations, and data freshness.

## Usage

```bash
scripts/dis status
```

## When to Use

- "Is my project fully indexed?"
- "What integrations are connected?"
- "When was data last refreshed?"
- Verifying project setup after onboarding

## Output

Returns project info, ingestion status, connected integrations, and data freshness timestamps.
